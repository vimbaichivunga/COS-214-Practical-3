# EventFlow — Astral Fields Festival

## Event Concept

Astral Fields Festival is a three-day outdoor music and arts festival held
across a single large venue. The festival is organised into physically
separate zones that each need to be opened, closed, reported on and sized in
the same way, while individual operational units inside each zone — stages,
gates, vendors, staff teams — must react differently to the same event-wide
announcement.

The venue is a single root event containing three top-level zones: the
**Plaza Zone** (main stage area), the **River Zone** (secondary stage and
transport hub) and the **Camping Zone** (overnight accommodation and support
services). The Plaza Zone contains a nested **Food Court** sub-zone, giving
the tree three levels of Composite nesting below the root (root → zone →
sub-zone → unit).
